# cockpit-core (Python)

The Python package of cockpit-core: exact betting money math (odds, de-vig, consensus and live consensus, Kelly staking, settlement, expected profit and the variance band, the 8-dp bet-price helper, prediction-market break-even) and the hash-committed track-record proofs, plus the `cockpit-verify` command.
See the [repository README](https://github.com/kylemoore66-rgb/cockpit-core#readme) for usage, the error contract and how the Python and TypeScript packages relate.
