# cockpit-core (Python)

The Python package of cockpit-core: exact betting money math (odds, de-vig, Kelly staking, settlement) and the hash-committed track-record proofs, plus the `cockpit-verify` command.
See the [repository README](https://github.com/kylemoore66-rgb/cockpit-core#readme) for usage, the error contract and how the Python and TypeScript packages relate.
