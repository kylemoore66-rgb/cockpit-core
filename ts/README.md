# cockpit-core (TypeScript)

The TypeScript package of cockpit-core: exact betting money math (odds and the 8-dp bet-price helper, Kelly staking, settlement and its constants, expected profit and its variance band) and canonical bytes plus Merkle proofs, so a browser can recompute what the Python package publishes.
See the [repository README](https://github.com/kylemoore66-rgb/cockpit-core#readme) for scope, the error contract and the documented differences from Python.
